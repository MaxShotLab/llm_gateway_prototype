This maps the read-only `spec/reference/MAXSHOT_Tokens_PRD_v1.0(read only).md` to the Gateway UI prototype. The source PRD was not edited. Where it conflicts with later decisions, `spec/DECISIONS.md` and the owning `spec/` documents govern the prototype.

## Prototype boundary

Actions on the Tokenomics screen change local sample state only. Its wallet confirmation step is simulated; it does not connect a wallet, sign transactions, call contracts, post Earned Credit grants, or charge inference. The Provider Market uses illustrative supplier metrics. The internal Treasury/Risk UI named in PRD §2.2 lines 140–141 and the broader Agent Connect UI in PRD Appendix/next steps line 1261 are outside this user-facing pass. Gateway API, Usage and subscription views remain accessible inside Profile or Credits. The standalone AIT Earn link currently opens the live Vaults page at `app.maxshot.ai/yields`; that site's older Mint and other pages are outside this Gateway prototype.
