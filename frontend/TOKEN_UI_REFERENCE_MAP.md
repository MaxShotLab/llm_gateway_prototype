# MAXSHOT token UI reference map

This maps the read-only `Tokenomics/MAXSHOT_Tokens_PRD_v1.0(read only).md` to the Gateway UI prototype. The source PRD was not edited. Where it conflicts with later decisions, `Tokenomics/MAXSHOT_Decision_Gaps_and_Handoff_Addendum.md` and `Tokenomics/MAXSHOT_Unified_Gateway_App_Decisions.md` govern the prototype.

## Prototype boundary

Actions on the MAX & AIT screen change local sample state only; they do not connect a wallet, sign transactions, call contracts, post Earned Credit grants, or charge inference. The Provider Market uses illustrative supplier metrics. The internal Treasury/Risk UI named in PRD §2.2 lines 140–141 and the broader Agent Connect UI in PRD Appendix/next steps line 1261 are outside this user-facing pass. The existing Gateway API, Usage, and subscription views remain accessible inside Profile or Credits. The old app.maxshot.ai Mint, Dashboard, Staking, Markets, and Agents Factory portals are retired in the unified navigation; existing Vault behavior stays intact as the implementation reference.
