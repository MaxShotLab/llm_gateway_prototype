# Maxshot — Decisions and gap register

**Status:** Working decision record, updated 16 November 2026. This is the single override record for the Gateway, unified app and MAX/AIT handoff. The read-only source is [`reference/MAXSHOT_Tokens_PRD_v1.0(read only).md`](./reference/MAXSHOT_Tokens_PRD_v1.0%28read%20only%29.md) (unchanged). The state machine, integer mint quote and grant arithmetic that used to sit in this file's §3 and §5 now live in [SPEC_TOKEN.md](./SPEC_TOKEN.md); Gateway catalog/routing behavior (former §3.6) lives in [SPEC_PROVIDERS.md](./SPEC_PROVIDERS.md) and [SPEC_BILLING.md](./SPEC_BILLING.md).

## 1. How to use this file

The source PRD remains read-only at the founder's request. This file records later decisions and where they supersede older wording. For **rows marked Decided**, implement the decision over conflicting source wording. All other source requirements and release gates continue to apply. A decision here is a working product/engineering decision, **not** approval of token sale execution, Credit funding, legal availability or mainnet deployment.

Engineering links requirements and tests to the source section/ID and the decision ID. Do not implement the source's older separate-position, immediate-unlock, provenance-gated MAX mint or one-chain launch behavior. If a clause is not listed here, this file does not change it.
